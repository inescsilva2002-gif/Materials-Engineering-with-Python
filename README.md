# Material Selector in Python
This is a small Python project made to practice programming within the context of Materials Engineering.
I recently started learning Python after having only a basic background in Visual Basic, and I wanted to begin building simple projects related to my field.
The program helps select metallic materials according to properties such as density, strength, and cost.
I developed it mainly as a learning exercise and used AI tools to help me better understand concepts and structure parts of the code.
Through this project I practiced working with simple data filtering, and I plan to continue improving it as I learn more Python.

# Material Stress Calculator in Python
The program calculates the stress applied to a material using force and area inputs and compares the result with the material’s yield strength and tensile strength. Based on the calculated stress, the program determines whether the material:remains in the elastic zone, enters the plastic zone or fractures.
Currently, the calculator includes a few predefined materials such as: Steel S355, Pure Aluminum, Annealed Copper and Titanium Ti6Al4V.
This project was mainly developed as a learning exercise to practice loops and conditionals and user input handling
